## Usage

This module provides the `geotiff` dataset type, configured as such:

```json
{
    "type": "geotiff",
    "url": "https://example.com/elevation.tif",
    "projection": "EPSG:3857",
    "name": "My GeoTIFF Dataset"
}
```
