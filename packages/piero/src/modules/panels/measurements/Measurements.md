## Usage

This module adds a Measurements panel to the application that allows users to create measurements on the map.

Users can:

- Create point-to-point distance measurements
- Create multi-point distance measurements
- Create area measurements
- View measurement results in different units
- Clear individual or all measurements
- Toggle measurement visibility
