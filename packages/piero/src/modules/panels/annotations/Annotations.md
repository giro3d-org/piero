## Usage

This module adds an Annotations panel to the application that allows users to create, edit, and manage vector annotations on the map.

Users can:

- Create point, line, and polygon annotations
- Edit annotation geometry and properties
- Style annotations with different colors and styles
- Import and export annotations as GeoJSON files
- Toggle annotation visibility
