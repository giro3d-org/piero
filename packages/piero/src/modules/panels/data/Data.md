## Usage

This module adds a Data panel to the application that provides a comprehensive interface for managing all datasets in the scene.

Users can:

- View a list of all loaded datasets
- Toggle dataset visibility
- Adjust dataset opacity
- Reorder datasets (bring to front, send to back)
- Delete datasets
- Access dataset-specific actions and settings
