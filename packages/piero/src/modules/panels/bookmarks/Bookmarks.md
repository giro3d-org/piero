## Usage

This module adds a Bookmarks panel to the application that allows users to save and manage camera positions (viewpoints).

Users can:

- Save the current camera position as a bookmark
- Navigate to saved bookmarks
- Rename and delete bookmarks
- Organize bookmarks for quick access to frequently used views
