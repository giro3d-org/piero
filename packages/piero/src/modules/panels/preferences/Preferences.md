## Usage

This module adds a Preferences panel to the application that allows users to save their own
settings, such as the color theme.

> [!note]
> This module works by setting the `data-bs-theme` Bootstrap attribute on the container of the Piero
> application (the DOM element that was specified when creating the app with `createPieroApp()`)
