## Usage

This module provides the `obj` dataset type, configured as such:

```json
{
    "type": "obj",
    "url": "http://example.com/path/to/dataset.obj",
    ...
}
```

See [OBJDataset](/api/@giro3d/piero-plugin-obj/type-aliases/OBJDataset) for all available options.
